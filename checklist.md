# Checklist de Conformidade Técnica CNPD para Etiquetas Web

**Regulatory Standard:** Orientações Técnicas CNPD e RGPD  
**Maintained by:** [TAVARDT Portugal](https://ag.tavardt.com/pt/)  

---

## Technical Audit Points

* **Bloqueio Prévio Rigoroso:** Todos os scripts não essenciais devem permanecer inativos até consentimento expresso.
* **Consent Mode v2 em Modo Restrito:** Inicializar ad_storage, ad_user_data e analytics_storage como 'denied'.
* **Gestão Transparente de Cookies:** Permitir a alteração e revogação do consentimento a qualquer momento de forma acessível.
* **Prevenção de Fuga de PII:** Redigir URLs e dados de formulários antes de qualquer envio para plataformas externas.
